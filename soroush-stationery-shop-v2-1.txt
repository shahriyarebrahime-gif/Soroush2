# Soroush Stationery Shop v2
Next.js + TypeScript + React

### تغییرات این نسخه
- ورود/ثبت‌نام با ایمیل به‌جای شماره موبایل
- ساختار OTP ایمیلی
- فرم کامل ثبت سفارش: نام، موبایل، استان، شهر، آدرس، کدپستی، روش دریافت و توضیحات
- صفحه Checkout اختصاصی
- پرداخت آنلاین عمداً غیرفعال
- شماره حساب فقط نمونه است
- پنل ادمین با دسترسی مبتنی بر ایمیل در ساختار پروژه
- طراحی جدیدتر، responsive، glassmorphism، نورپردازی و micro-interaction

### اجرای محلی
npm install
npm run dev

### Demo OTP
123456

### ایمیل‌های مدیر نمونه
admin@soroush-shop.ir
manager@soroush-shop.ir

قبل از Production این موارد حتماً باید اضافه شوند:
1. سرویس ایمیل واقعی برای OTP
2. دیتابیس
3. Session/JWT امن سمت سرور
4. rate limiting و انقضای OTP
5. اتصال واقعی ثبت سفارش به دیتابیس
6. درگاه پرداخت معتبر
7. مدیریت موجودی و ارسال
